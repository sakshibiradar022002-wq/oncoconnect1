ℹ️ How It Works

VELTRUVIA keeps a hash-linked audit trail (a local, single-node chain). Every medical record operation is hashed and chained to the previous entry, so any later tampering with past entries is detectable. The actual encrypted records remain in the secure database — only their cryptographic fingerprints are stored in the chain. This is an audit log with tamper evidence, not a distributed blockchain network.
