How It Works

1

Install the Server

The VELTRUVIA Server runs in the background (system tray on Windows, or a cloud VM — see DEPLOY.md). It links every app and stores all data.

2

Install Your App

Patient & Lab: download the APK on an Android phone. Doctor: install the Windows software. Sign in with your credentials — no server address needed.

3

Everything Stays in Sync

A symptom logged on a phone appears in the Doctor software instantly. Lab results reach the patient the moment they're uploaded. All data is saved on the server.
